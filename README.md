# Velvet.Site

This repository contains the official Blazor demo and showcase site for Velvet.

The project is used to experiment with real-time rendering, scene management, and WebGL integration through Velvet inside Blazor WebAssembly.

It also serves as the primary playground for testing new engine features, demos, and rendering experiments during development.

> ⚠️ Velvet is currently under active development and some features or APIs may change over time.
